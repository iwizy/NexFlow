# Reference CLI Preview: No Conformance Claim

The first `0.5.0-alpha.1` developer preview is released, if separately authorized,
**without an NF-CLI claim**. This document is an explicit non-claim, not a
standalone claim record or certificate. The actual archives and source must be
selected by the [release review](../release/0.5-preview-review.md).

The candidate implements the bounded [NF-104 profile](../docs/0.5-cli-contract.md)
and [package/API/command behavior](../docs/reference-cli-preview.md). It checks
syntax, discovery association and frozen local schema shape, then optionally
projects declared inspection/static graph facts. Complete semantic, Core,
extension and runtime layers remain `not-run`. Success authorizes no execution.

There is also no complete NF-SCHEMA/NF-SEMANTIC, Core Profile, extension,
provider, runtime or independent implementation-conformance claim. The older
[repository validator statement](REPOSITORY-VALIDATOR-CLAIM.md) retains its own
source and partial scope; it is not copied into a CLI certificate. Frozen
semantic catalog comparisons include internal migration surfaces, not complete
public CLI semantic coverage. The wider RFC-0011 remains Draft.

Native installation, safe diagnostics, archive integrity and dependency evidence
prove their named candidate-bound checks. They do not establish full standards
conformance, an OS sandbox or publisher trust. A later claim needs its own
versioned record, profile/coverage/exclusion evidence and maintainer decision.
