## Compatibility And Claim Ceiling

- Manifest `specVersion: "0.1"`, the 17-kind schema family, independent claim
  and readiness formats, maintained profiles and experimental CLI output
  versions are unchanged. No `0.2` manifest dialect, schema bundle, package,
  tag, release, version bump or new deprecation is introduced.
- The evaluated validator checks maintained examples. The repository prototype
  checks selected local inputs; neither proves full cross-manifest semantics,
  complete policy evaluation or execution readiness.
- The draft repository-validator claim is still bound to
  `bb8d559b665337b1a9f4c007bfa8335dec92a79a`, not the assessed main. This
  checkpoint does not refresh or publish that claim, certify a validator, accept
  a Draft RFC, or establish `NF-CLI`, `NF-RUNTIME` or executable extension support.
- Minimal Team deliberately has three manifests; Solo Developer has ten;
  six complete projects retain sixteen each. Existing legacy participant and
  migration-only forms remain within their documented scope. The complete
  examples do not provide a normal selected active definition/effective agent
  configuration merely because their schemas pass.
- No orchestration, provider calls, secret access, executable extension loading,
  live integration or automatic approval enforcement is added. Application
  guardrails are not an operating-system sandbox.
- Current Unreleased evaluation evidence has real failures and not-tested
  gates. [Fidelity](../evaluation/fidelity/README.md),
  [isolation](../evaluation/isolation/README.md),
  [supply-chain](../evaluation/supply-chain/README.md) and
  [Linux lifecycle](../evaluation/lifecycle/linux/README.md) record separate
  experiments. Green consistency checks do not make those gates pass, resolve
  published dependency risks, select a language or approve an architecture.

The source check record is not an independent security review, artifact
lifecycle review or new maintainer release sign-off. It records no new
vulnerability scan or risk acceptance. Preserve the published foundation and
milestone decisions and their real dates.
