# Draft v0.4.0 Notes — Source And Decision Milestone

Status: readiness **ready-with-notes**, publication **not authorized**. These
are prepared notes, not an announcement of a published release or CLI package.
See the [completion review](0.4-completion-review.md) and its exact-source record.

NexFlow `v0.4.0` is prepared as the Runtime Decision Readiness milestone after
published `v0.3.0`: repository source, architecture decision and evaluation
evidence with checksums. Executable assets, native apps/installers, evaluation
capsules and embedded runtimes are not offered by this format.

All four independent language candidates have source-bound hard-gate outcomes.
Under the explicitly amended criterion, TypeScript/Python have weighted
scorecards and native target measurements; Rust/Go remain rejected for Windows
confinement and retain null/excluded measurements. The original all-four-success
objective is false. Accepted RFC-0025 selects TypeScript/layout B only for
unsigned developer validation and future host-interface design.

The October 28 advisory refresh and 40 per-input applicability dispositions
close the current source-milestone review. Upstream affected versions remain
in frozen locks, including fast-uri 3.1.8; they were not repaired or declared
generally safe. Fixed-schema validation, disabled native install scripts,
hash-locked local wheels and exclusion of external toolchain binaries define
the bounded conclusions. General online/native provisioning, URI authorization,
arbitrary-schema hosting or executable distribution require a new review.

No workflow execution, provider call, credential broker, executable extension,
production enforcement, stable public ABI, full project semantics or new
NF-CLI/NF-RUNTIME conformance is supplied. Native evaluation records are
source/cohort-bound observations, not general target-support promises.
Signing/notarization were not performed and are not applicable to the offered
non-binary assets; native delivery reopens applicable trust requirements.

Manifest `specVersion: "0.1"`, schema/profile/claim and diagnostic formats, and
experimental package versions remain unchanged. There is no authored-manifest
migration from this repository milestone. Support remains one maintainer,
pre-release best effort, no SLA, backup or on-call promise.

The dated October 26 not-ready review and earlier draft notes remain historical.
Future publication must select the exact final commit, obtain its separate
publication instruction, bind the tag and verify downloaded assets/checksums.
The `0.5` reference-tooling preview and any runtime implementation are separate.
