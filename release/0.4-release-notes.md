# Draft v0.4.0 Release Notes

Status: **unpublished, not-ready**. Proposed release notes only; no release date,
tag, asset or package is announced. Read the
[candidate-bound readiness review](0.4-readiness-review.md) before publication.

NexFlow `v0.4.0` is intended to be the Runtime Decision Readiness milestone
following the published `v0.3.0` semantic-consistency milestone. The proposed
format is a specification/decision source snapshot with review evidence and
checksums, without executable release assets or an installable CLI.

The snapshot records independent TypeScript, Python, Rust and Go validation-only
prototypes and their exact-source fidelity, diagnostic, dependency, isolation,
native lifecycle and measurement evidence. Accepted RFC-0025 selects TypeScript
and separate static/host packages for unsigned developer validation and future
host interface design. TypeScript and Python qualify in that bounded comparison;
current Rust/Go Windows confinement failures remain explicit and unscored.

Preparation is blocked by the unchanged release plan's four-candidate comparison
criterion and newly matched dependency advisories. Only 42 of the original 84
metric cells are measured; rejected candidates' remaining cells are null.
The October 26 scan matches `fast-uri@3.1.8` and other declared toolchain
components. This draft does not label the candidate vulnerability-free or treat
the October 15 evidence as current release approval.

No workflow execution, provider calls, credential broker, executable extension,
production enforcement, durable runtime store or new full-product conformance
is implemented or promised. Future package extraction, pure-kernel work and
graph/init ports require their own implementation and verification. Native
qualification applies only to its pinned evaluation artifacts and actual cohorts,
not general target support. Signing/notarization were not performed; trusted
native application delivery is not offered. Support remains pre-release best
effort with one maintainer, no SLA, backup or on-call promise.

Manifest `specVersion: "0.1"`, schemas, profiles, conformance claims, diagnostic
formats and experimental package versions remain independent and unchanged.
No authored-manifest migration follows merely from this repository milestone.
Historical releases, RFC-0023, failed reports and dated preparation checkpoints
remain available. The `0.5` tooling preview and runtime implementation are
separate milestones, not features announced by these notes.
