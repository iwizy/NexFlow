# NexFlow v0.5.0-alpha.1 — Reference Tooling Preview

**Unpublished prerelease notes.** Proposed tag `v0.5.0-alpha.1`; publication
requires a separate maintainer instruction and the exact
[release review](0.5-preview-review.md). This is the first alpha on the 0.5 line,
not a beta or stable 0.5.0. Latest published stable milestone remains v0.4.0.

Two private npm-compatible tarballs provide `@nexflow/cli` and
`@nexflow/validation` `0.5.0-alpha.1` with a complete pinned production closure,
original legal texts and 18 embedded schema files. They require external Node
26.13.1/npm 11.20.0. No runtime is bundled and no npm registry publication is
proposed. The tag/package version is separate from manifest `specVersion: "0.1"`,
embedded snapshot/bundle version and `0.5-preview.1` output.

The CLI implements help/version, explicit-root `validate`, declared `inspect`
and explanatory static `graph`, with safe text/JSON diagnostics and documented
exits. It does not execute declarations, call providers, load executable
extensions, fetch remote schemas or initialize credentials. `init`, whole-project
semantic/Core/extension validation, runtime policy/enforcement and orchestration
are unsupported. This preview carries **no NF-CLI conformance claim**.

Use the [installation and quick start](../docs/reference-cli-installation.md)
and verify the final asset digests before extraction. Native target records are
required for Ubuntu 24.04 AMD64, macOS 15 ARM64 and Windows Server 2025 AMD64,
including genuine predecessor upgrade/rollback, offline commands, Unicode paths,
refusals and scoped uninstall. The final review names the exact checked images,
source revisions, artifacts, failures and remaining limitations.
