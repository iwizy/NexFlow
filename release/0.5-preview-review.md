## Architecture Lens

The pure library, root-bound CLI adapter and host/runtime remain separate.
The selected package surface is unchanged from the adopted profile; internal
catalog regressions do not expand public semantics. All commands are read-only,
init is deferred and output never grants execution authority. Embedded schemas
are fixed specification inputs; qualification covers the shipped API engine,
not arbitrary external schema engines. No new manifest, architecture or runtime
acceptance is inferred from this release review.
